Projects

Project One - A To-Do App

The To-Do App is a simple, clean, and responsive task management interface built using only HTML and CSS. Designed as a static front-end project, it showcases how semantic HTML elements and modern CSS techniques can be used to create an attractive and user-friendly layout without the need for JavaScript. The app features a task input section, a styled task list, and interactive hover effects to enhance the user experience. Although it does not support dynamic functionality like adding or removing tasks, it serves as an excellent example for beginners learning to structure and style web pages. This project is ideal for practicing front-end skills, experimenting with CSS Flexbox or Grid, and building the foundation for a fully functional to-do application in the future.

Project Two - Weather App

The Weather App is a simple and intuitive web application designed to provide real-time weather information for any city or location. Built with a user-friendly interface, the app displays current temperature, weather conditions, humidity, wind speed, and location-based forecasts. Using clean HTML and CSS for layout and styling, and optionally powered by a weather API (if JavaScript is used), this project demonstrates how design and functionality can come together to deliver practical, real-world information in a visually appealing format. Ideal for practicing responsive design and integrating external data, the Weather App is a great example of combining frontend development skills with user-centered design.
